# M2-L1: GitHub pull request lab

This document records the submission requirements for the xbrain M2-L1 lab.

## Submission fields

- Branch: `l1/LRN-39c66277/m2-l1`
- Commit SHA: copy the full 40-character SHA of the commit on this PR's head branch.
- PR URL: copy the URL of this pull request in this repository.

## Verification

1. Open the PR URL and confirm the pull request exists.
2. Confirm its head branch is `l1/LRN-39c66277/m2-l1`.
3. Open the Commits tab and confirm the submitted SHA belongs to this PR.
4. Have the manager verify the PR. Self-merging does not count as verification.

Keep the pull request open for manager verification.
